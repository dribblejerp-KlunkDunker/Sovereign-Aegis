WHAT A KEY CHANGES HERE

With a Gemini key — “Execute Epistemic Audit” also sends the claim text to Google's Gemini (the model picked in Settings) for deep adversarial analysis layered on the local heuristics; the completion toast says GEMINI AUDIT COMPLETE when it ran. Without one, the same button runs the fully-offline regex + fallacy-lexicon engine and nothing leaves your device. Either way the result tells you which ran, and a failed API call degrades to the offline engine and says so — never a live answer posing as one.

With a Fact Check key — every audit also searches published ClaimReview records from IFCN-signatory fact-checkers in the PUBLISHED FACT-CHECKS panel below. Without one, the panel says so plainly; a failed lookup is reported as a failure and is never treated as evidence about the claim.

The tradeoff: a key means data leaves the device — the claim text goes to Google's model, or the claim's keywords go to Google's fact-check lookup. That is the only outbound traffic in this view. Keys live in tab memory only (see Settings) and are wiped on reload; with no key configured, nothing leaves the device.
