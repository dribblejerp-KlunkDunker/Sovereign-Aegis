## What this is

An offline-first, browser-native intelligence and cognitive-defense training suite.
Vanilla ES modules, WebCrypto, Web Audio, Canvas, pure mathematical estimators —
zero build tools, zero runtime dependencies. Four pillars (Cognitive Fortification,
Real-Time Protection, Signal & OSINT Forensics, Collective Defense) on a shared
foundation (StateStore, persistence, WebCrypto, attempt logging, Bayesian
competency estimation). Full architecture and feature inventory: `PROJECT.md`.

## Standing standards (inherited from the repo-wide honesty work, Sep 2026)

The host repo now enforces, via its check suite, that no displayed number may be
fabricated (`check-fabricated-metrics.js`) and that status claims are backed by
real probes. AEGIS predates that gate but shares the rule: every gauge, status
label, and score shown to a learner must be measured or estimated from real
attempts — never simulated to look alive. New AEGIS features should assume that
standard applies.

## How to run

No build step for the multi-file app: serve the directory statically
(`serve.mjs` / `serve.cmd` in this folder) and open it. The standalone single-file
build is generated by `build-standalone.mjs` when needed.
